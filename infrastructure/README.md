# Infrastructure

Deployment and observability configuration, introduced in Phase III (Weeks 7–9).

- `docker/` — Dockerfiles and compose files for local reproducible environments.
- `kubernetes/` — Deployment/Service/ConfigMap manifests, resource requests/limits,
  probes, used for the Week 9 orchestration and failure experiments.
- `prometheus/` — scrape configuration for the inference gateway and cluster.
- `grafana/` — dashboards for request rate, latency, errors, CPU, RAM, throughput.

Not started — first used in Week 7.
